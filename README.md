# 在线智能作文批改系统（Essay Grading System）

基于大语言模型（LLM）的轻量化智能作文批改 Web 系统，面向课堂教学与 NLP 课程对照实训场景。

传统作文人工批改存在工作量巨大、评分主观化、无法量化学生写作短板等问题。本系统依托大语言模型技术，结合提示词工程、Web 可视化开发、批量文件解析与数据可视化绘图技术，实现单篇/批量作文的智能批改、四维打分、可视化分析与对照实验。

## ✨ 功能特性

- **单篇作文批改**：支持直接粘贴文本，或上传 Word（.docx）/ PDF 文件解析后批改
- **批量多文档批改**：一次上传多个 Word/PDF 文件，批量批改并导出 CSV 报表
- **四维得分可视化**：语言表达 / 逻辑结构 / 素材内容 / 立意思想 四项打分
  - 雷达图展示单项能力分布
  - 与学段平均分对比的薄弱环节柱状图
- **双模型推理**：本地轻量模型（Ollama + Qwen2.5-7B，离线免费）与云端大模型（DeepSeek API）自由切换
- **双提示词策略对照**：一次性单轮提示词 vs 分步多轮提示词，页面可切换并对比
- **对照实验面板**：内置 20 篇人工标注作文数据集，支持两组单一变量对照实验
  - 实验一：提示词策略性能对比（一键生成柱状图）
  - 实验二：本地/云端模型批改精度对比（一键生成柱状图）
- **一键清空缓存**：重置页面缓存，重新批改

## 🚀 快速开始

### 1. 环境要求

- Python 3.9+
- （可选）Ollama + Qwen2.5-7B 本地模型，用于离线推理模式
- （可选）DeepSeek API Key，用于云端推理模式

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置 API 密钥（使用云端模式时）

本项目**不硬编码任何密钥**，云端 DeepSeek API Key 通过环境变量 `DEEPSEEK_API_KEY` 提供：

```bash
# Windows PowerShell
$env:DEEPSEEK_API_KEY = "你的DeepSeek密钥"

# Linux / macOS
export DEEPSEEK_API_KEY="你的DeepSeek密钥"
```

> 也可以写入 `.env` 文件（已加入 .gitignore，不会被提交）。

### 4. 部署本地模型（使用离线模式时）

1. 安装 [Ollama](https://ollama.com/)
2. 拉取模型：`ollama pull qwen2.5:7b`
3. 保持 Ollama 托盘程序运行（默认监听 `127.0.0.1:11434`）

### 5. 启动系统

```bash
streamlit run main.py
```

浏览器自动打开 http://localhost:8501

## 📝 使用说明

1. **侧边栏参数设置**：选择学段（小学/初中/高中/大学）、评语风格、提示词策略、模型模式
2. **单篇批改**：左侧粘贴作文或上传文档 → 点击「开始AI批改」→ 右侧展示总分、四维得分、错误修正、素材推荐、修改建议、评语与可视化图表
3. **批量批改**：上传多个 Word/PDF → 「开始批量批改全部文档」→ 生成结果表格并导出 CSV
4. **对照实验**：点击「打开对比实验说明面板」→ 加载数据集 → 一键生成两组对比柱状图
5. **图表与报表输出位置**：所有图表自动保存至桌面 `data_images/` 文件夹，CSV 报表保存至桌面，规避 Windows 系统目录权限问题

## 🧪 对照实验设计

- **实验一（提示词策略）**：固定同一篇作文/学段/评语风格，对比「一次性单轮提示词」与「分步多轮提示词」的 JSON 解析成功率、错误检出率与耗时
- **实验二（模型规模）**：固定提示词策略，对比「本地 Qwen2.5-7B」与「云端 DeepSeek」在纠错、逻辑打分、素材匹配维度的精度

内置 `essays.json` 数据集包含小学记叙文、初高中议论文、大学学术议论文的人工标注样本，可开展批量对照测试。

## ⚠️ 注意事项

- 请勿在代码中硬编码 API 密钥；密钥请通过环境变量或 `.env` 提供
- 作文全文过长时会被截断至前 1000 字送入模型（防止请求超限）
- 模型输出异常时系统会自动降级为兜底分数模板，并提示切换策略重试
